# Completion report — {{project_title}}

> Generated per run by `scripts/report_generator.py` into `.devpipeline/runs/<run>/final-report.md`.
> This template documents the required sections; the generator fills them from evidence only.

1. Run id, mode, profile, final status (COMPLETED only after a passing deterministic gate)
2. Original request
3. Technology stack & architecture summary
4. Agents invoked (with activation reasons)
5. Requirements & acceptance-criteria matrix — VERIFIED / IMPLEMENTED_UNVERIFIED / MISSING / BLOCKED
6. Tasks (status, attempts, failure reasons)
7. Quality gate table (status + reason per gate)
8. Integration, build and test evidence (commands, exit codes, counts, logs)
9. Security findings · AI evaluation (deterministic vs live) · performance
10. Repair iterations · remaining issues · pre-existing failures
11. Assumptions · non-goals · known limitations
12. Source revision, integration branch, artifact paths
13. Local startup & test instructions · recommended next steps
